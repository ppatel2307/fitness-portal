BACKGROUND MUSIC
================
Put your soundtrack file in THIS folder and name it:

    veggi-theme.mp3   (preferred)

Other accepted names: veggi-theme.m4a  or  veggi-theme.ogg

That's it. Reload index.html and hit ENTER — the track plays on loop,
and the speaker button (bottom-right) mutes/unmutes it.

No internet or YouTube connection is used. The file plays straight from
this folder.
